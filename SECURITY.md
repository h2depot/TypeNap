# Security Policy for TypeNap

## Supported versions

Security updates are provided for the latest release only.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ |
| Older versions | ❌ |

## How to report vulnerabilities

If you have found a potential security vulnerability, please do not report it through a public GitHub issue. Please report via the GitHub Private Vulnerability Disclosure functionality.

(Tips regarding reporting problems privately can be gained from [here](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately#privately-reporting-a-security-vulnerability)) 

### Vulnerabilities Scope

Please process the items listed below according to the instructions above.

 - Unauthorized access to local user data
 - Arbitrary code execution
 - Vulnerabilities in the application's update mechanism
 - Security issues related to Tauri commands or IPC
 - Path traversal or unintended file access
 - Or other critical bugs that cause harm to users

## Security issue handling process

After receiving a security report, we will review and validate the issue.
If the vulnerability is confirmed, we will work on a fix and release a security update when appropriate.

Please avoid publicly disclosing the vulnerability until a fix has been released.

## There is no bug bounty

This project does not currently operate a bug bounty program.

Security reports are greatly appreciated; however, no monetary rewards or other compensation are offered for vulnerability reports.

We are sorry for this...
