# Contributing to TypeNap

If you have any questions or suggestions for improving functionality, please follow the steps below; it will help us address your issue more quickly.

## Asking Questions

Please create a new issue using the tag `typenap-question`.

When creating the issue, it would be helpful if you could explain the unclear points in detail.

Any questions are welcome. Feel free to ask even small questions.

## Suggesting Features and Improvements

If you have an idea for a new feature or an improvement to an existing feature, please create an issue using tag `typenap-suggestion` first and describe your proposal.

When creating the issue, please explain:
 - What you would like to improve or add
 - Any implementation ideas you may have
 - Areas that may need to be rewritten, etc.

For significant changes, please wait for feedback before starting implementation.

Pull requests for bug fixes and small improvements are also welcome.

## Thank you!

Thank you for reading this CONTRIBUTING.md, and also thank you for browsing our TypeNap repository.
