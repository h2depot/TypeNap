# TypeNap fonts

Nunito Sans is used for Latin text, with M PLUS 1p for Japanese. Both use the actual 800 (ExtraBold) font face; synthetic bold is disabled in App.css.

Downloaded from Google Fonts on 2026-09-30:
https://fonts.googleapis.com/css2?family=M+PLUS+1p:wght@800&family=Nunito+Sans:wght@800&display=swap

The font files are bundled locally, so runtime network access is not required. Each family is distributed under the accompanying SIL Open Font License.
